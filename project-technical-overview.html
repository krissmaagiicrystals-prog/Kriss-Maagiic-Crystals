SECTION 01

System Architecture & Technology Stack

The platform is engineered on modern cloud-native serverless architecture optimized for high performance, rapid page load times, SEO indexing, and robust transaction security.

🖥️ Frontend & Edge Layer

Next.js 15 App Router with React Server Components (RSC), TailwindCSS styling, Framer Motion animations, and global Vercel Edge CDN distribution.

🗄️ Database & Storage

MongoDB Atlas (v8.0) with Mongoose ODM for resilient document persistence, paired with Cloudflare R2 Object Storage for high-speed image & video delivery.

💳 Dual Payment Infrastructure

Razorpay & Cashfree integrated with server-side signature verification webhooks and automatic currency settlement into INR.

✉️ Messaging & Communications

Hostinger Enterprise SMTP via Nodemailer for automated transactional order confirmations, booking status emails, and password recovery.

SECTION 03

Core Functional Engines & Logic

1. Multi-Currency Engine & Financial Normalization

The platform contains a centralized currency computation engine located in src/lib/money.ts. It automatically identifies the customer's geographic currency based on IP or user selection (INR, USD, GBP, EUR, AUD, CAD, etc.). When orders or bookings are settled, the system records both the native customer currency transaction and the calculated inrAmount.

2. Dual Spiritual Booking Modes

  • Scheduled Live Video Consultations: Requires the customer to pick an exact calendar date and slot from available admin-defined slots.
  • Asynchronous WhatsApp Voice Note Readings: Does not require slot scheduling. Displays "Flexible delivery within 24–48 hours via WhatsApp Voice Notes" and records booking as unscheduled for admin turnaround.

3. Multi-Currency Excel Financial Reports

The Admin dashboard exports both Monthly Summaries and Full 5-Sheet Database Workbooks. Each line displays the native currency paid by international customers (e.g. £10 GBP) while converting and aggregating all revenue columns into INR totals for flawless accounting reconciliation.

SECTION 05

Admin Account Management & Password Reset Guide

Administrative access to the backend control center is available at /admin/login. If the admin password is ever forgotten or needs to be changed, use one of the two standard procedures below:

Method 1: Instant Reset via Dedicated CLI Script (Recommended)

A dedicated password reset utility has been placed at scripts/reset-admin-password.ts. You can run this command from the project root in your terminal: 

npx tsx scripts/reset-admin-password.ts "krissmaagiicrystals@gmail.com" "YourNewStrongPassword@2026"

This script connects directly to MongoDB Atlas, hashes the password using Bcrypt with 12 salt rounds, sets the user role to admin, and enables the account immediately.

Method 2: Direct MongoDB Atlas Web Portal Update

  1. Log in to MongoDB Atlas using your credentials.
  2. Navigate to Browse Collections ➔ krissmaagiic database ➔ users collection.
  3. Locate the document where email: "krissmaagiicrystals@gmail.com".
  4. Update the passwordHash field with a freshly hashed Bcrypt string (or run Method 1 above).
  5. Ensure role: "admin" and active: true.

SECTION 06

Deployment, GitHub Sync & Maintenance

The platform follows continuous integration and automatic deployment (CI/CD) practices:

  • Automatic Deployment: Every push to the main branch of the GitHub repository (krissmaagiicrystals-prog/Kriss-Maagiic-Crystals) automatically triggers an optimized production build on Vercel.
  • Database Backups: MongoDB Atlas executes continuous automated point-in-time cloud snapshots for zero-data-loss disaster recovery.
  • Local Development: Run npm run dev to launch the local test server at http://localhost:3000.
